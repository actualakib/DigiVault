# Module 2: Advanced Security & Privacy

## 5. Session Timeout [Zareen Sultana 232-35-483]
**Assigned feature:** Authenticated areas

Authenticated pages sign the user out 15 minutes after the session starts, regardless of activity. The dashboard countdown is shared across pages and tabs and is not reset by clicks or navigation. This client-side timeout complements, but does not replace, JWT expiration.

**Existing code:** [session handling](../../frontend/js/api.js).

## 6. Digital Watermarking [Zareen Sultana 232-35-483]

Watermarks are added to PDFs generated by the File Converter.

**Existing code:** [PDF watermarking](../../security/watermark.js), [converter controller](../../backend/controllers/fileConverterController.js).

## 7. Anti-Tampering [Adnan Akib 232-35-009]
**Assigned features:** Personal Vault, Financial Vault, Certificates

The Anti-Tampering activity feed records selected file and folder operations, including uploads, downloads, deletions, and folder creation. It provides an audit trail; it does not perform cryptographic integrity checks or detect changes made outside DigiVault.

**Existing code:** [audit logger](../../security/audit.js), [audit-log queries](../../database/queries/auditLogs.js), [profile activity view](../../frontend/js/profile.js), [Personal Vault controller](../../backend/controllers/personalVaultController.js), [Financial Vault controller](../../backend/controllers/financialVaultController.js), [Certificates controller](../../backend/controllers/certificatesController.js).
