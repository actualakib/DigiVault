# Module 2: Advanced Security & Privacy

## 5. Zero-Knowledge Asset Encryption
**Assigned features:** Personal Vault, Financial Vault, Certificates, Quick Records, Password Manager

Selected fields, including saved passwords and bank account numbers, are encrypted. This is not a zero-knowledge design: the backend holds the encryption key. Uploaded files are not encrypted by this field-encryption code.

**Existing code:** [field encryption](../../security/encryption.js), [password manager controller](../../backend/controllers/passwordManagerController.js), [quick-records controller](../../backend/controllers/quickRecordsController.js).

## 6. Digital Watermarking & Anti-Tampering
**Assigned features:** Personal Vault, Financial Vault, Certificates

Watermarks are added to PDFs generated by the File Converter. Tamper detection or document authenticity verification is not currently implemented.

**Existing code:** [PDF watermarking](../../security/watermark.js), [converter controller](../../backend/controllers/fileConverterController.js).

## 7. Granular Sharing & Time-Bound Access
**Assigned features:** Personal Vault, Financial Vault, Certificates

Not currently implemented. Existing vault routes support the owner's file operations; they do not provide sharing permissions or expiring access links.

**Related existing code:** [Personal Vault routes](../../backend/routes/personalVault.js), [Financial Vault routes](../../backend/routes/financialVault.js), [Certificates routes](../../backend/routes/certificates.js).

## 8. Comprehensive Security Audit Logs
**Assigned features:** Authentication and all features

Audit logging is implemented for selected actions, including sign-in, PIN actions, file operations, and password-manager actions.

**Existing code:** [audit logger](../../security/audit.js), [audit-log queries](../../database/queries/auditLogs.js), [profile and audit-log controller](../../backend/controllers/profileController.js).
