Frequently Asked Questions

  1. What can I store in DigiVault?

    You can organize personal files, financial documents, certificates, quick records, and saved credentials in their dedicated vaults.

  2. Where are my files and records stored?

    Vault records and uploaded files are stored locally by the DigiVault backend in its SQLite database and storage folder. Google sign-in requires an internet connection.

  3. How does DigiVault protect my account?

    Sign in with Google and unlock the vault with your security PIN. Selected password and bank-account fields are encrypted, but uploaded files are not encrypted by that field-encryption feature.

  4. Can DigiVault find text inside an image?

    Yes. Image uploads are processed with OCR where supported, and recognized text can be viewed in the Personal Vault and searched where OCR indexing is enabled.

  5. How do I find and copy a file ID?

    After upload, the file ID appears in the success message and on the vault card. Use Copy ID to copy it for the File Converter.

  6. How do I convert an existing vault file?

    Open File Converter, choose a vault, and enter the file ID shown on its card. The converter creates a PDF you can download from the converted-files list.

  7. Why was I signed out?

    DigiVault signs you out 15 minutes after your session starts. The countdown continues while you use the site and does not reset when you click buttons or navigate.

  8. What does Anti-Tampering activity show?

    Account → Security lists recent file and folder events, including uploads, downloads, deletions, and folder creation when those events are recorded.

  9. Can I create my own folders?

    Yes. Financial Vault and Certificates let you create folders to organize your uploaded files.

  10. Can I share files or export a backup from DigiVault?

    File sharing and in-app backup export are not currently available. DigiVault stores data on the computer running its backend.
